# my_fitness_date

Red social fitness con comunidades, actividades deportivas y un modo opcional de citas.

**Estado:** desarrollo inicial del MVP (no apto para usuarios reales).

## Componentes del producto

- **Fitness Community:** publicaciones y relaciones sociales orientadas al deporte.
- **Fitness Together:** grupos y actividades.
- **Fitness Dating:** espacio romántico voluntario y separado.
- **Gym Shield:** excluir personas del mismo gimnasio, o permitirlas únicamente cuando los horarios de entrenamiento no se crucen.

## Seguridad y alcance

Esta primera etapa usa datos de demostración: todavía no hay cuentas, servicios remotos, verificación de edad, moderación ni protección de datos en servidor. **No se deben incorporar usuarios reales ni publicar la aplicación como producto terminado.** Las reglas de Gym Shield deberán verificarse y aplicarse en el backend antes de lanzar la beta.

El desarrollo se revisa mediante ramas y pull requests. Nunca publicar credenciales o datos personales en el repositorio.
