# Registro de experimentos
**Estado:** ningún experimento real aprobado o desplegado en esta revisión.

Cada experimento requiere hipótesis, población/rol, consentimiento cuando aplique, asignación estable, métrica primaria, guardrails de abuso/privacidad/accesibilidad/costos, periodo, criterio de parada, feature flag y responsable de reversión.

El tamaño de muestra y la significación estadística no se presumen; pilotos cualitativos se etiquetan como tales. No alterar seguridad, consentimiento ni acceso a moderación como variable experimental.
